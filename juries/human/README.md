# juries/human — the human expert jury (Level 3)

Five human literary readers — critics, scholars, translators, and writers — evaluated four stories with AI authorship disclosed: the LLM jury's top tier (S_02, S_06) plus two diagnostic anchors (S_07, S_04).

- `FORM_SPEC.md` — the full specification from which the evaluation form was built: criteria, scales, item texts, and the confirmation message, preserved as deployed. Respondents saw the stories as "Story A–D"; the mapping (published in the paper) is A = S_02, B = S_06, C = S_07, D = S_04.
- `responses_anonymized.csv` — every collected response value (scores, editorial decisions, detection answers, free-text reflections), one row per respondent, apart from the optional acknowledgment name and email fields, which were collected solely for acknowledgments and paper copies and are removed here. One clause of one free-text answer, naming the genres of a respondent's past professional work, is additionally redacted in place and marked `[genre detail redacted for respondent privacy]`; no score or categorical value is altered. The empty first (`Timestamp`) column is structural — the aggregation script reads columns by position.

Aggregated scores and the human-vs-LLM comparison are regenerated by `analysis/level3_aggregate.py`; reference copies live in `analysis/expected_outputs/` (`level3_*.csv`). Panel recruitment, consent, and role disclosures are described in the paper's methods.
