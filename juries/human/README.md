# juries/human — the human expert jury (Level 3)

Five human literary readers — critics, scholars, translators, and writers — evaluated four stories with AI authorship disclosed: the LLM jury's top three (S_06, S_02, S_07) plus one contrast story (S_04), on which the LLM jurors had split most widely.

- `FORM_SPEC.md` — the full specification from which the evaluation form was built: criteria, scales, item texts, and the confirmation message, preserved as deployed. Respondents saw the stories as "Story A–D"; the mapping (published in the paper) is A = S_02, B = S_06, C = S_07, D = S_04.
- `responses_anonymized.csv` — every collected response value (scores, editorial decisions, detection answers, free-text reflections), one row per respondent, apart from three fields that are removed here: the optional acknowledgment name and email, collected solely for acknowledgments and paper copies, and the answer on years of professional experience, which together with profession and working language could point to an individual reader. No analysis uses it. One clause of one free-text answer, naming the genres of a respondent's past professional work, is additionally redacted in place and marked `[genre detail redacted for respondent privacy]`; no score or categorical value is altered. The empty first (`Timestamp`) column is structural — the aggregation script reads columns by position.

Aggregated scores and the human-vs-LLM comparison are regenerated by `analysis/level3_aggregate.py`; reference copies live in `analysis/expected_outputs/` (`level3_*.csv`). Panel recruitment, consent, and role disclosures are described in the paper's methods.
