# juries/ — two receptions

The corpus was judged twice, by differently constituted panels:

- [`llm/`](llm/) — five LLM jurors blind-scoring all eight stories, three repetitions each (120 evaluations), inside a fictitious prize frame.
- [`human/`](human/) — five human literary readers evaluating four selected stories, with AI authorship disclosed.

The divergence between the two receptions is one of the paper's central findings; each subfolder's README describes its materials and where the derived scores live.
