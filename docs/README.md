# docs/ — pre-registration & verification

- `preregistration/` — the pre-registration documents, **locked and preserved verbatim** as historical record, together with their dated addenda and two correction notes in which the authors disclose errors found after locking (including re-dating Run 1 via vendor chat timestamps). Because these files are frozen, they retain the working project's internal texture: private-repository file paths (a few coincide with names that also exist here — the frozen text always refers to the archive versions, including `analysis/RESEARCH_AUDIT_2026-06-21.md`, which is an internal audit log retained in the archive); open action notes and task numbers whose completion is recorded in later corrections; unfilled placeholders (a repository URL template, signature lines); and project names — *SOLIT* (the pilot event that preceded the study) and *CFS* (an early internal name used alongside SIMPLEX). None of these are links into this repository's structure.
- `preregistration/CODING_GUIDE.md` — the instruction document handed to the independent second coder, likewise preserved as the instrument they received (second-person voice and workbook file names included).
- `VERIFICATION.md` — a summary of the four independent verification passes the dataset and analyses have been through (reproduction audit, claim-by-claim check, blind ground-truth coding audit, and the pre-release integrity sweep that found the duplicated juror response).
- `EXTRACTION_CORRECTIONS_2026-08-20.md` — dated correction note for three region codings of real writers in the masters roster and the collection-label normalization, with their (small) effects.
- `DATA_REPAIR_2026-08-20.md` — dated note recording one duplicated LLM-jury response found in a pre-release integrity audit, its recovery from the original vendor session, and the (small, S_05-confined) effect on the results.
- `CORRECTIONS_FOLLOW_UP_2026-08-20.md` — closes the two actions that were still open in the earlier correction notes: the Run 1 dating (confirmed by the lead author) and the canonical basis for story word counts.

Suggested reading order: `preregistration/PREREGISTRATION_v1.md` (design and coding scheme) → `preregistration/PREREGISTRATION_LEVEL2.md` (LLM jury) → `preregistration/PREREGISTRATION_LEVEL3.md` (human jury) → the addenda and corrections → `VERIFICATION.md`.
